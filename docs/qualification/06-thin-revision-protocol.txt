STEP 6 HARNESS REVISION: DIAGNOSE, VALIDATE, RECALIBRATE, THEN STOP FOR REVIEW

Preserve the failed cal001 calibration and its original frozen protocol.
Do not run the main experiment during this repair step.

Diagnostics, fixed before execution: three canonical initial states; 10 warm-up
rounds and 30 measured rounds; randomized order of Clock, Lookup, and Full/NoList/
Small at K=1,8,32. Full is the original empty-batch function. NoList removes its
result-list accumulation. Small carries only mode/count/expected output instead
of all the original arguments. Clock includes diagnostic dispatch/clock binding;
it is not an isolated hardware-clock latency. These are controlled whole-function
variants, not an additive decomposition of the failed calibration's CPU cost.

Thin adapter: call the SAME compiled Cost.Expand predicate through a small Prolog
adapter. Python remains the experiment driver, validator and analysis language.
PeTTa src/translator.pl translate_clause builds the predicate name from the MeTTa
function name and appends the output argument: Cost.Expand therefore has arity6.
No PLN operation is reimplemented in Prolog. The helper hash must equal step five.
The custom Prolog file is loaded only on explicit request to Runtime.run.

Measure one expansion at a time with direct Janus process_time_ns calls, around
the compiled predicate. Input preparation, callable-term construction, reporting
and result checks are outside the local operation clock; they are not free in an
end-to-end benchmark. Dispatch/cut and boundary-clock overhead remain inside.
Check the full solution set has exactly the validated result BEFORE timing.
Check every timed result AFTER its clock, without accumulating output lists.
The identical original input terms are reused; no output becomes the next state.

Validation: all 13 saved states, both candidates; existing 20 warm-up pairs plus
two measured pairs per state; keep 30 empty samples and 30 direct clock probes.
Also deliberately provide one wrong expected result and require rejection.
This checks the new adapter's execution/guards; it is not the main cost comparison.

Recalibration: only after validation passes, three canonical states, K=1, same
20 warm-up pairs, 30 balanced measured pairs, 30 empty samples, unchanged 10%
empty-p95/faster-median gate. The explicit protocol revision removes batching
because this adapter avoids accumulation and times each individual operation.
No threshold relaxation, overhead subtraction or inference-rule change. If it
fails, retain the failure; if it passes, report readiness, not a main result.
