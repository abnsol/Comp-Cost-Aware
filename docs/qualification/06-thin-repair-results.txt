Repair
Python continues to orchestrate, validate and analyze the experiment. A small
Prolog adapter calls the SAME Cost.Expand predicate compiled by pinned PeTTa.
The underlying MeTTa helper hash matches the previously validated step-five helper.
No inference rule, truth formula, queue update or selector was reimplemented.
Runtime.run gains an optional bootstrap_path for this explicit adapter only;
existing callers retain their original command construction and behavior.

The direct adapter builds the callable term before the start clock, measures one
compiled native expansion, stops the clock, then checks the full output tuple.
It discards each result after checking it instead of retaining a batch list.
Each call receives the unchanged original input queues. No result becomes the
next expansion's input. It does not restore hardware caches or allocator history.
Clocks still use embedded Python process_time_ns through Janus, now called directly
from Prolog rather than through the general MeTTa clock wrapper.
Residual-choicepoint handling and clock/bridge overhead remain inside the window.
Startup, input preparation, callable construction, output checks and printing
remain outside this LOCAL timing window; they are not free in a full query run.

Native-equivalence checks
Before timing, findall verifies that the compiled predicate returns EXACTLY one
solution and that it equals the previously validated native result. Timed calls
use once to bound residual choicepoints only after this determinism check on the
same ground inputs. Every timed output is also checked for groundness and exact
equality after its end clock. A missing, additional or changed result fails closed.
Both candidates passed on all 13 states, with 20 warm-up pairs and two measured
validation pairs each. A deliberately wrong expected output was correctly rejected.
This establishes observed equivalence for this fixed workload, not every PLN task.
